# Git Workflow & Conventional Commits

HEMA follows standard **Conventional Commits** and branch hygiene to keep history clean and transparent.

---

## 🌿 Commit Types

- `feat`: A new feature or user-facing capability
- `fix`: A bug fix or patch
- `docs`: Documentation changes
- `style`: Formatting, CSS tokens, visual design tweaks
- `refactor`: Code refactoring without behavioral changes
- `perf`: Performance improvements
- `test`: Adding or updating tests
- `chore`: Maintenance, dependencies, build configurations

---

## 🚀 Branch Naming Convention

- `feat/feature-name`
- `fix/issue-description`
- `docs/guide-name`
- `refactor/component-name`

---

## 🔒 Pull Request Checklist

1. Run `npm run lint` and verify 0 lint errors.
2. Run `npm run build` and verify 0 build errors.
3. Keep pull requests focused on a single responsibility.
