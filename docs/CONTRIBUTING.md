# Contributing to Hema

Thank you for your interest in contributing to **Hema**! We welcome contributions from developers of all skill levels.

---

## Code of Conduct

Please foster an inclusive, supportive, and friendly community. Treat all contributors with respect regardless of experience or background.

---

## How to Contribute

### 1. Find an Issue or Propose a Feature
Before making large changes, please browse existing [GitHub Issues](https://github.com/TheVicky1/Hema/issues) or open a new issue to discuss your ideas.

### 2. Fork & Branch
Fork the repository and create a feature branch off `main`:

```bash
git checkout -b feature/my-amazing-feature
```

### 3. Make Changes & Validate Locally
Make your edits and run local validation commands:

```bash
npm run lint
npm run build
```

### 4. Commit Conventions
Use clear, descriptive commit messages:
- `feat: add blood bank location filter`
- `fix: correct dark mode button label`
- `docs: update getting started guide`

### 5. Submit a Pull Request
Push your branch to GitHub and submit a Pull Request targeting the `main` branch. Fill out the [Pull Request Template](../.github/PULL_REQUEST_TEMPLATE.md) with details about your changes.

---

## Questions & Help

If you have questions or need assistance, feel free to open a discussion or ask directly within your PR/Issue thread.
