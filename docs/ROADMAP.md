# HEMA Strategic Roadmap

Our phased engineering roadmap outlines the trajectory from demonstration prototype to a verified community healthcare coordination platform.

---

## 📍 Phased Engineering Milestones

### Phase 1: Foundation & Demonstration Platform (Completed)
- [x] Full migration to React 19, Vite 7, and React Router v7.
- [x] Responsive 72px Command Navigation with active tab indicator and mobile drawer.
- [x] Donor directory with live blood group and city filters.
- [x] Accessible profile inspection modal with focus trapping and masked contact credentials.
- [x] Dual-theme engine supporting pure white light mode and OLED dark mode (`#0C0C0C`).
- [x] Atmospheric wave canvas engine with hardware-accelerated CSS animations.
- [x] Automated GitHub Actions CI/CD quality gates and Vercel edge deployment.

### Phase 2: Proximity & Geospatial Matching (In Progress)
- [ ] Client-side Haversine radial distance calculations.
- [ ] Distance radius filter slider (5 km, 10 km, 25 km, 50 km).
- [ ] OpenStreetMap and Nominatim city coordinate integration.
- [ ] Geolocation permission toggle with privacy-preserving coordinate truncation (~1 km).

### Phase 3: Emergency Dispatch & Social Outreach (Upcoming)
- [ ] Native Web Share API integration for one-click WhatsApp and Twitter mobilization.
- [ ] RFC 5545 `.ics` iCalendar 56-day replenishment reminder generation.
- [ ] Web Audio API synthetic confirmation chimes and mobile haptic pulses.
- [ ] Progressive Web App (PWA) manifest and offline directory caching.

### Phase 4: Healthcare Partner & Hospital Portal (Future)
- [ ] Verified hospital and certified blood bank administrative dashboards.
- [ ] Blood drive scheduling and urgent requirement broadcast channels.
- [ ] Secure SMS and WhatsApp emergency dispatch relay.
