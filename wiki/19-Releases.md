# Releases & Changelog

Historical record of all milestone releases for the HEMA platform.

---

## 🏷️ Release History

### v1.0.0 - Production Foundation Release (November 2026)
- **Modern Stack**: Full migration to React 19, Vite 7, and React Router v7.
- **Design System**: Dual-mode theme engine with pure white light mode and deep OLED dark mode (`#0C0C0C`).
- **Brand Identity**: Cohesive inline crimson logo (`#E11D48`) and atmospheric wave canvas.
- **Donor Directory**: Interactive directory with instant blood group and city filtering.
- **Profile Modal**: Accessible donor profile dialog with keyboard trapping and masked contacts.
- **Automated CI/CD**: GitHub Actions workflow verifying dependencies, linting, and builds.
