# GitHub Community & Issue Governance

HEMA uses structured labels and issue templates to ensure smooth contributor onboarding.

---

## 🏷️ Issue Labels
- `good first issue`: Beginner friendly tasks scoped to a single file.
- `hacktoberfest`: Open source celebration tasks.
- `bug`: Confirmed defects or styling bugs.
- `enhancement`: New features or capabilities.
- `documentation`: Wiki and markdown improvements.
- `a11y`: Web accessibility and screen-reader enhancements.
