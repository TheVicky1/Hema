# GitHub Community & Collaboration

HEMA is an inclusive, welcoming open-source project where everyone is treated with kindness, empathy, and respect.

---

## 💬 Community Channels

- **GitHub Discussions**: Ideation, architectural proposals, and general Q&A.
- **GitHub Issues**: Structured bug reports, documentation tasks, and feature requests.
- **Pull Requests**: Code review, collaboration, and continuous integration feedback.

---

## 🏷️ Issue Label Taxonomy

| Label | Color | Purpose |
| :--- | :--- | :--- |
| `good first issue` | `#7057ff` | Simple, beginner-friendly task taking 5-20 minutes |
| `first-timers-only`| `#bfdadc` | Reserved exclusively for newcomers to open source |
| `documentation`    | `#0075ca` | Wiki, README, and markdown improvements |
| `hacktoberfest`    | `#ff79c6` | Eligible for open-source celebration programs |
| `community`        | `#0e8a16` | Collaborative community initiatives |
| `a11y`             | `#22c55e` | Accessibility and screen-reader enhancements |
