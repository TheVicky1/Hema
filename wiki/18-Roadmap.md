# Strategic Project Roadmap

Our phased engineering roadmap outlines the trajectory from demonstration concept to real-world healthcare integration.

---

## 📍 Phased Milestones

### Phase 1: Foundation & Demonstration UI (Current - Complete)
- [x] React 19 + Vite 7 Single Page Application.
- [x] Donor directory with live blood group and city filters.
- [x] Profile inspection modal with masked contact privacy.
- [x] Atmospheric wave canvas engine with dual light/dark themes.
- [x] Automated CI quality gates and Vercel edge deployment.

### Phase 2: Geospatial Distance Matching (Upcoming)
- [ ] Integration with OpenStreetMap / Nominatim API for city geocoding.
- [ ] Radial distance calculation using the Haversine formula.
- [ ] Radius filter slider (5 km, 10 km, 25 km, 50 km).

### Phase 3: Real-Time Notifications & PWA
- [ ] WebSockets / Supabase real-time updates for emergency donor broadcast.
- [ ] Progressive Web App (PWA) manifest and service worker for offline discovery.
- [ ] SMS / WhatsApp emergency dispatch relay.

### Phase 4: Healthcare Facility Portal
- [ ] Verified hospital and blood bank administrative portals.
- [ ] Blood drive scheduling and donation appointment slots.
